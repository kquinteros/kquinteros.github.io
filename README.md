# PhyloFignatico

This is the repository for [phylofignatico.com](https://phylofignatico.com), my personal website built using **Quarto**.  

## About

This site showcases my work in biology, genomics, and bioinformatics. It is built with:

- [Quarto](https://quarto.org) for website generation
- Markdown and YAML for content and site configuration
- HTML/CSS/JavaScript for customization

## Structure

- `_quarto.yml` – Quarto project configuration  
- `index.qmd` – Home page  
- `posts/` – Blog posts  
- `_site/` – Rendered website (ignored by Git)  

## Deploy

The site is hosted on GitHub Pages via the `gh-pages` branch.
